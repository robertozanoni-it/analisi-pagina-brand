Brand Audit Suite (Offline)

Standalone • Nessuna API • Offline

1) Impostazioni progetto

Lavora per confronto: Brand vs Competitor. Puoi usare Screenshot o HTML/Testo per ognuno.

Modalità Screenshot

Carica 1+ screenshot per il Brand e (opzionale) 1+ screenshot per il Competitor. La app calcola palette, coerenza visiva, contrasto stimato e densità visiva.

Modalità HTML / Testo

Incolla testo o carica un file .html. L’app fa analisi strutturale (leggibilità, specificità, “tu/noi”, numeri, segnali di fiducia) + checklist manuale.

Checklist manuale (brand)

Questa parte serve per misurare ciò che offline non si può “indovinare”: posizionamento, valori, narrativa, personalità.

Ctrl/Cmd per selezione multipla.

Suggerimento: dopo l’audit puoi usare Stampa del browser → “Salva come PDF”.

Esegui un audit per generare i punteggi e le raccomandazioni.
